# FB Ads Tracker (BIGCAT)

เว็บบันทึกแชทที่มาจาก Facebook Ads + หน้าภาพรวม ต้นทุน/funnel แทนชีต "ระบบเก็บข้อมูล Funnel จาก Facebook Ads"

- หน้าเว็บ: HTML/CSS/JS ล้วน ไม่ต้อง build — วางบน GitHub Pages
- หลังบ้าน: Google Apps Script + Google Sheet ไฟล์ใหม่
- ยังไม่ใส่ `API_URL` = เปิดใน **โหมดตัวอย่าง** (ข้อมูลจำลอง) ดูหน้าตาได้ทันที

```
index.html
assets/css/style.css
assets/js/config.js      ← ใส่ API_URL ตรงนี้
assets/js/api.js         เรียก Apps Script / จำลองในเบราว์เซอร์
assets/js/calc.js        กติกาการนับทั้งหมด (funnel, lead ซ้ำ, KPI, ข้อความสรุป)
assets/js/charts.js      กราฟ SVG
assets/js/app.js         หน้าจอทั้งหมด
assets/js/demo-data.js   ข้อมูลจำลอง
apps-script/Code.gs      หลังบ้าน
apps-script/appsscript.json
```

## ติดตั้ง (ประมาณ 15 นาที)

### 1) หลังบ้าน — Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `FB Ads Tracker – DB`
2. เมนู **Extensions → Apps Script** → ลบโค้ดเดิม วางเนื้อหา `apps-script/Code.gs`
3. (ถ้าอยากตั้งเขตเวลา) Project Settings → ติ๊ก *Show "appsscript.json"* → วางเนื้อหา `apps-script/appsscript.json`
4. แก้ `FIRST_USER` บรรทัดบน ๆ เป็นชื่อ/PIN ของตัวเอง
5. เลือกฟังก์ชัน `setup` → **Run** (ครั้งแรกจะขออนุญาต กด Allow)
6. เลือก `createFirstUser` → **Run**
7. (ย้ายข้อมูลเก่า) เลือก `importFromOldSheet` → **Run** — อ่านชีตเดิมแบบอ่านอย่างเดียว ไม่แก้ชีตเดิม
8. **Deploy → New deployment** → ประเภท *Web app*
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก URL ที่ลงท้าย `/exec`

> แก้ Code.gs ภายหลัง ต้อง **Deploy → Manage deployments → ✎ → Version: New version** ทุกครั้ง URL เดิมจึงจะได้โค้ดใหม่

### 2) หน้าเว็บ — GitHub Pages
1. เปิด `assets/js/config.js` ใส่ `API_URL: 'https://script.google.com/macros/s/.../exec'`
2. push ทั้งโฟลเดอร์ขึ้น repo
3. repo → **Settings → Pages** → Source: *Deploy from a branch* → `main` / `/ (root)` → Save
4. รอ 1–2 นาที เปิด `https://<user>.github.io/<repo>/`

## ใช้งาน
- **บันทึกแชท**: พิมพ์ชื่อ → เลือกโฆษณา → กดสถานะ → กดเลือกประเภทสินค้า (iPhone, iPad, MacBook …) + รุ่น (ไม่บังคับ) → บันทึก · แก้รายการประเภทสินค้าได้ที่ ตั้งค่า · เคส *5-ปิดการขาย* ใส่ยอดรับซื้อ + **วันที่ปิดได้** + **ปิดโดย** (ระบบบอกว่าใช้เวลากี่วันจากวันที่ทักครั้งแรก)
- **แคมเปญ** — หัวใจคือตาราง **รอบการยิง** (1 แถว = ยิงด้วยงบ/วันเดียวกัน ตั้งแต่วันไหนถึงวันไหน)
  - **ปรับงบ** = จบรอบเดิม + เริ่มรอบใหม่ให้อัตโนมัติ (มีปุ่ม −20% / +20% / +50%)
  - **หยุดยิง** = ใส่วันยิงวันสุดท้ายให้รอบที่ยิงอยู่ · **เปิดยิงรอบใหม่** = เพิ่มรอบ
  - **+ เพิ่มรอบยิง (ย้อนหลังได้)** = ใส่วันเริ่ม/วันจบ/งบ ของแคมเปญที่จบไปแล้วได้ตรง ๆ
  - ทุกแถวแสดงผลของรอบนั้น (วัน · ค่า Ads · Lead · Lead/วัน · ต้นทุน/Lead · ปิดได้) พร้อม ▲▼ เทียบรอบก่อน · กดแถวเพื่อแก้วันที่/งบ
  - **กรอกค่า Ads**: ยอด Amount spent จาก Ads Manager เป็นช่วงวันที่ · ระบบเตือนวันที่ยังไม่กรอก
- **แคมเปญ** หน้ารายการ: กราฟจิ๋ว 14 วัน (Lead + เส้นงบ) · ผลปรับงบล่าสุด · ปุ่ม **กรอกทีเดียวทุกแคมเปญ** (ค่า Ads หลายแคมเปญในฟอร์มเดียว)
- **ภาพรวม**: *รับซื้อได้เป็นสินค้าอะไร* · การ์ด *ระยะเวลา ทัก → ปิดได้* (เฉลี่ย / ค่ากลาง / เร็วสุด / ช้าสุด + ตารางทุกเคส) · *ทดลองงบ* · *คัดลอกสรุป*
- **ตั้งค่า**: เป้าต้นทุน/เคส · ผู้ใช้/PIN

> เว็บเช็คเวอร์ชันหลังบ้านทุกครั้งที่เปิด — ถ้า Apps Script ยังเป็นตัวเก่าจะขึ้นแถบแดงและ**ไม่ให้บันทึก** (กันข้อมูลหายหลังรีเฟรช)

## อัปเดตโค้ด (ติดตั้งไปแล้ว)
1. วาง `apps-script/Code.gs` ใหม่ทับของเดิม → Save
2. เลือก `setup` → Run (รันซ้ำได้ ไม่ลบข้อมูล — จะสร้างแท็บใหม่ และสร้างแคมเปญ/Ad set จากข้อมูลเดิมให้)
3. Deploy → Manage deployments → ✎ → Version: **New version** → Deploy
4. push ไฟล์หน้าเว็บชุดใหม่ขึ้น GitHub — ถ้าทับ `assets/js/config.js` ให้ใส่ API_URL เดิมกลับ

## กติกาการนับ (อยู่ใน `assets/js/calc.js`)
| สถานะ | ขั้นสูงสุด |
|---|---|
| 1-ทักแล้วเงียบ | 1 |
| 2-มีข้อมูลเครื่อง, X-ของไม่ตรง | 2 |
| 3-ประเมินราคาแล้ว, 7-สินค้าไม่รับซื้อ | 3 |
| 4-นัดรับของ | 4 |
| 5-ปิดการขาย | 5 |
| 6-ขอซื้อสินค้า | ไม่เข้า funnel (นับเป็น Lead ฝั่งขาย) |

ชื่อลูกค้าเดียวกันในแคมเปญเดียวกัน = 1 คน (ใช้แถวที่ไปได้ไกลสุด)

## ความปลอดภัย
- PIN เก็บเป็น SHA-256, token เซ็นด้วย HMAC อายุ 30 วัน
- Google Sheet หลังบ้านอย่าแชร์สาธารณะ — เว็บเข้าผ่าน Apps Script เท่านั้น
- ทุกการแก้ไขถูกบันทึกในแท็บ `Log`

## แท็บในชีตหลังบ้าน
Chats · Ads · AdSets · Campaigns · Budgets (งบที่ตั้ง) · Users · Config · Log  (แท็บ Spend เก่ายังอยู่แต่เว็บไม่ใช้แล้ว)

## ดึงข้อมูลจาก Facebook อัตโนมัติ
ดึง: ค่า Ads รายวัน · งบ/วัน (สร้าง/ปิดรอบยิงให้เอง) · เปิด/หยุดยิง · แคมเปญ / Ad set / โฆษณา · จำนวนแชทที่ Facebook นับ
· **รายชื่อลูกค้าที่ทักเพจ** (ชื่อ · รูป · วันที่ทักครั้งแรก · ข้อความแรก) ย้อนหลัง 3 เดือน — **อ่านอย่างเดียว**
- คนที่ทักวันที่มีโฆษณาตัวเดียวได้แชท → สร้างแชทให้เลย (ป้าย "ตรวจโฆษณา")
- วันที่มีหลายโฆษณา → ขึ้นในหน้า บันทึกแชท "รอเลือกโฆษณา" พร้อมโฆษณาที่แนะนำ กดทีเดียว
- วันที่ไม่มีโฆษณายิงเลย → "ทักมาจากช่องทางอื่น" (เก็บไว้ดู ไม่นับใน Lead/ต้นทุน)
- โทเคนต้องมีสิทธิ์: `ads_read`, `pages_show_list`, `pages_read_engagement`, `pages_messaging` และมอบ **เพจ** ให้ System User (แอปต้องเพิ่มการใช้งาน Messenger ก่อน จึงจะเห็น pages_messaging)
1. วาง `Code.gs` ใหม่ → Save → Run `setup`
2. ⚙️ **Project Settings → Script Properties → Add script property** — ชื่อ `FB_TOKEN` · ค่า = โทเคน System User (ads_read) → Save
   *(ห้ามใส่โทเคนในโค้ดหรือบน GitHub)*
3. Run `testFacebook` → ต้องขึ้น "เชื่อมต่อได้ ✓" (ครั้งแรกจะขออนุญาตเชื่อมต่อภายนอก กด Allow)
4. Run `syncFacebook` → ดึงย้อนหลัง 90 วัน
5. Run `installAutoSync` → ดึงเองทุก 1 ชั่วโมง (ย้อนหลัง 3 เดือนครั้งแรกอาจใช้ 2–3 รอบ)
6. Deploy → Manage deployments → ✎ → New version
- บัญชีโฆษณาตั้งที่ `FB_AD_ACCOUNT` บนสุดของ Code.gs
- จับคู่แคมเปญด้วยชื่อ (ครั้งแรก) แล้วจำ id — เปลี่ยนชื่อใน Facebook ระบบเปลี่ยนตามให้ทุกแท็บ
- วันที่มีตัวเลขจาก Facebook แล้ว ค่า Ads ที่กรอกมือของแคมเปญนั้นในวันนั้นจะไม่ถูกนับ
